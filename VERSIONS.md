# Versions

Each version is a git tag (`v1_blog_style` … `v6_case_study_animation`) on the last commit of that version.

- **On GitHub:** open the repo's Tags page, or browse the code at a version with `https://github.com/broccoli-tree-design/website/tree/v3_salome_font_color`. To diff two versions: `https://github.com/broccoli-tree-design/website/compare/v2_googly_eyes...v3_salome_font_color`.
- **Locally:** run `git checkout v3_salome_font_color`, then `npm install && npm run dev`. Run `git checkout main` to come back.
